# 나의 마이솔 블로그 서식 기준 (2026-10-31)

## 화면 기준
사용자가 제공한 네이버 블로그 편집 화면을 기준으로 작성한다.

1. 제목: `[요가 수련일지] ...` 형식.
2. 첫 줄: `YYYY년 M월 D일 · 수련종류`. 기울임꼴(Italic) 적용.
3. 스마트스토어: `https://smartstore.naver.com/my-mysore/products/13836041036` 링크를 삽입하고 네이버가 제공하는 **상품 이미지/제목/설명 포함 링크 미리보기 카드**로 표시되는지 확인. 일반 URL 자동 링크만 생성되면 미완료.
4. 본문: 원문 문단/빈 줄을 유지하고 문장 표현을 임의로 바꾸지 않는다.
5. 강조: 원문에서 굵게 표시한 구절만 Bold 처리. 자동으로 강조 구절을 새로 선택하지 않는다.
6. 이미지/미리보기 카드와 본문 사이의 여백은 네이버 에디터의 기본 문단 간격을 유지한다.

## 자동화 수용 기준
- 제목이 제목 필드에 있고 본문에 중복되지 않음
- 날짜 줄 Italic 적용 확인
- 스마트스토어 카드가 실제로 렌더링되는지 확인 (URL 문자열만으로 성공 판정하지 않음)
- 원문 Bold 범위가 보존됨
- 문단/줄바꿈 유지
- 발행 전 사용자 승인 및 미리보기 확인

## 현재 구현 한계
현재 Chrome 확장 프로그램은 승인된 JSON에서 제목과 **일반 텍스트 본문**을 복사한다. Italic, Bold, 네이버 링크 카드 생성은 **아직 구현/검증되지 않았다**. SmartEditor ONE의 링크 카드 생성은 네이버 UI의 동작에 의존하므로 단순 HTML 삽입이나 URL 붙여넣기로 성공을 가정하지 않는다. 서식 지원이 검증되기 전에는 발행을 자동화하지 않는다.

## 향후 데이터 구조
승인 JSON에 원문 강조 구간을 명시적으로 보존할 수 있는 필드(예: 별도 rich text blocks)를 추가하되, 기존 `content` 문자열 형식은 계속 지원한다.
